## Ranked feature proposals

1. **Verify the intended release in CI** · proposed · 1–2 days. Let a release job supply its expected repository ID, destination ref and candidate commit to the offline verifier. Require full Git object verification. Test two valid bundles in one clone and a mismatch in each expected field, plus missing objects and an indeterminate outcome. SLSA's verifier accepts a trusted source identity from the caller and in-toto statements identify subjects by digest. [SLSA verifier](https://github.com/slsa-framework/slsa-verifier) · [in-toto Statement](https://github.com/in-toto/attestation/blob/main/spec/v1/statement.md)
2. **One-call execution for configured reads** · proposed · 3–5 days. Prototype a host opt-in that reuses planning, policy, mediation and receipt generation for explicitly allowed read tools. Verify denied and approval-required calls never dispatch. After BENCH-1–3, compare the existing façade, compact graph views and the prototype on both hosts with at least three repetitions per condition. Target at most four median calls per lookup and at least 25% fewer result bytes than the existing façade on each host at equal completion. Measure whole-turn usage separately. MCPProxy provides a discovery comparator. MCP-Atlas supplies a precedent for scoring task completion independently of the sequence of calls. [MCPProxy repository](https://github.com/smart-mcp-proxy/mcpproxy-go) · [Discovery design](https://docs.mcpproxy.app/features/search-discovery/) · [MCP-Atlas paper](https://arxiv.org/abs/2602.00933)
3. **Preview a policy change offline** · proposed · 2–3 days. Evaluate old and new policies on caller-supplied redacted cases. Report changed decisions and invalidated plan digests separately. Check unchanged decisions with a changed digest, new denial, widened allowance and insufficient input. Verify zero ledger writes, issued capabilities or raw arguments in output. OPA's decision logging and masking provide a reference for the input boundary. [Benign policy-drift fixtures](https://github.com/adimalkar/mcp-repro-gate/pull/76) · [OPA decision logs](https://www.openpolicyagent.org/docs/management-decision-logs)
